Make sure server connects to your routers IP range. 

Verify via:
```bash
ip -br link
ip -br addr
cat /etc/network/interfaces
```

### What to look for

**1. `ip -br link`** lists the network interfaces. Your real Ethernet port will be named something like **`eno1`** or **`enp0s31f6`**.

- It shows **`UP`** → the cable is connected. ✅
- It shows **`DOWN`** or **`NO-CARRIER`** → no cable signal. Check that the cable is firmly in, try another router LAN port, or try another cable.

**2. `ip -br addr`:** the **`vmbr0`** line should show **`192.168.8.50/24`**.

- If it still shows `192.168.100.2`, the change didn’t apply. Run `ifreload -a` again, or reboot with `reboot`.

**3. `cat /etc/network/interfaces`** shows the network settings. It should look like this, though your port name may differ:

```
iface vmbr0 inet static
        address 192.168.8.50/24
        gateway 192.168.8.1
        bridge-ports eno1
```

## Manually update

### Step 1: Edit the network file

bash

```bash
nano /etc/network/interfaces
```

Use the **arrow keys** to move to these two lines and change them:

**From:**

```
        address 192.168.100.2/24
        gateway 192.168.100.1
```

**To:**

```
        address 192.168.8.50/24
        gateway 192.168.8.1
```

### Step 2: Fix the hosts file

bash

```bash
nano /etc/hosts
```

Find the line starting with `192.168.100.2` and change only that number to **`192.168.8.50`**. Keep the rest of the line, e.g. `pve.home.lan pve`. Save with **Ctrl + O → Enter → Ctrl + X**.

### Step 3: Apply and test

bash

```bash
ifreload -a
ip -br addr
ping -c 3 192.168.8.1
```
