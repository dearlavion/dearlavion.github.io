### Part 1: Prepare your Mac (about 15 minutes)

**1.1 Install the free apps**

- **Docker Desktop:** docker.com. Install it, open it once and wait until it says “Engine running”.
- **balenaEtcher:** etcher.balena.io

**1.2 Download Proxmox**

- Go to proxmox.com → **Downloads** → **Proxmox VE ISO Installer** (the latest version).

**1.3 Create your work folder and SSH key**

Open **Terminal** and run:

bash

```bash
mkdir -p ~/homelab
mv ~/Downloads/proxmox-ve_*.iso ~/homelab/
ssh-keygen -t ed25519        # press Enter through the prompts
cat ~/.ssh/id_ed25519.pub    # copy this whole line
```

### Part 3: Build the auto-install ISO (about 10 minutes)

**3.1 Start a Linux container**

bash

```bash
docker run -it --name pvetool --platform linux/amd64 -v ~/homelab:/work debian:trixie bash
```

Your prompt changes to something like `root@abc123:/#`. You’re now inside Linux.

**3.2 Install the Proxmox tool** (inside the container)

bash

```bash
apt update && apt install -y wget ca-certificates xorriso
wget https://enterprise.proxmox.com/debian/proxmox-archive-keyring-trixie.gpg \
  -O /usr/share/keyrings/proxmox-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/proxmox-archive-keyring.gpg] http://download.proxmox.com/debian/pve trixie pve-no-subscription" \
  > /etc/apt/sources.list.d/pve.list
apt update && apt install -y proxmox-auto-install-assistant
```

**3.3 Check the answer file and build the ISO**

bash

```bash
cd /work
proxmox-auto-install-assistant validate-answer answer.toml
proxmox-auto-install-assistant prepare-iso proxmox-ve_*.iso --fetch-from iso --answer-file answer.toml
ls
exit
```

- `validate-answer` should report the file is valid. If it shows an error, fix `answer.toml` and run it again.
- After `ls`, you should see a new file ending in **`-auto-from-iso.iso`**.
- If you need to come back later, re-enter the container with `docker start -ai pvetool`.

### Part 4: Flash the USB drive (about 5 minutes)

1. Plug the USB drive into your Mac using the USB-C adapter.
2. Open **balenaEtcher**.
3. **Flash from file** → choose `~/homelab/...-auto-from-iso.iso` (the **auto** one, not the original).
4. **Select target** → your **16GB USB**. Check the size.
5. Click **Flash!** and wait until it finishes verifying.
6. If macOS says **“disk not readable”**, click **Eject**. That’s normal.

---

### Part 5: Install Proxmox on the EliteDesk (about 20 minutes, hands-off)

1. Put the EliteDesk **next to your router**.
2. Plug in:
    - The **Ethernet cable** into the EliteDesk and a **LAN port** on the router (not WAN)
    - The **USB drive** into a USB-A port on the **back** of the EliteDesk
    - The **keyboard**
    - **Power**
3. Press the power button and **immediately tap F9** repeatedly.
4. Wait **5 seconds**, press **Down arrow once**, then press **Enter**.
5. **Don’t touch anything else.** The installer picks “Automated Installation” by itself after 10 seconds, installs, and reboots.
6. Wait **20 minutes**, then **pull out the USB drive**. You can return the keyboard now.

### Part 6: Manage proxmox via Web dashboard (easiest)
use the IP in Step 5.1

1. In Safari, open **`https://192.168.8.50:8006`** and log in.

If any install fails:
The Tailscale install then stopped at a **different, expected error**: Proxmox comes set up to use its **paid “enterprise” update sources**, and without a subscription they reply **401 Unauthorized**. That breaks `apt-get update`, which the Tailscale installer needs. This is the “switch to No-Subscription” step I mentioned earlier. Let’s do it now.

### Option A: Web dashboard (easiest)

1. In Safari, open **`https://192.168.8.50:8006`** and log in.
2. In the left panel, click **pve** → **Updates** → **Repositories**.
3. Click the line containing **`enterprise.proxmox.com/debian/pve`** → click **Disable**.
4. Click the line containing **`enterprise.proxmox.com/debian/ceph-squid`** → click **Disable**.
5. Click **Add** → choose **No-Subscription** → click **Add**.
6. You’ll see a warning that No-Subscription isn’t recommended for production. That’s fine for a homelab.
