### A. On VM 104

**1. Fix permissions and create the SSH key**

```
chown runner: /home/runner
```

```
mkdir -p /home/runner/.ssh && chown -R runner: /home/runner/.ssh && chmod 700 /home/runner/.ssh
```

```
sudo -u runner ssh-keygen -t ed25519 -N "" -f /home/runner/.ssh/id_ed25519
```

```
cat /home/runner/.ssh/id_ed25519.pub
```

Copy the whole printed line.
```
root@vm-runner:/home/runner/actions-runner# cat /home/runner/.ssh/id_ed25519.pub

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIOwy2R+Vybs8JyygcfPYY7vMtLYbTpWQMqB18GvTDTr4 runner@vm-runner
```

### B. On Proxmox (pve → Shell)

**2. Authorize the key.** Replace `PASTE_LINE_HERE` with the copied line:

It will append to existing keys 
```
echo >> /root/.ssh/authorized_keys
echo 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIOwy2R+Vybs8JyygcfPYY7vMtLYbTpWQMqB18GvTDTr4 runner@vm-runner' >> /root/.ssh/authorized_keys
```

### C. Back on VM 104

**3. Test the login.** It should print the Proxmox version with no password:

```
sudo -u runner ssh -o StrictHostKeyChecking=accept-new root@192.168.8.50 pveversion
```

**4. Create the state folder**

```
mkdir -p /var/lib/homelab-state && chown runner: /var/lib/homelab-state && chmod 700 /var/lib/homelab-state
```

**5. Give `runner` Docker access**

```
usermod -aG docker runner
```

```
cd /home/runner/actions-runner && ./svc.sh stop && ./svc.sh start
```

```
sudo -u runner docker run --rm alpine echo ok
```
