
## Guide: create VM 104 (vm-runner) in the Proxmox UI
Clone Template VM created in 6.4 
1. In the left tree, right-click **9000 (ubuntu-2404-tmpl)** → **Clone**.
2. Set VM ID `104`, Name `vm-runner`, Mode **Full Clone**, Target Storage **local**, Format **qcow2**.
3. Continue from **Step 6 (Memory)** of the guide.

![[Pasted image 20261119003459.png]]

|Setting|Value|
|---|---|
|VM ID / Name|`104` / `vm-runner`|
|vCPU / RAM|1 core / 1024 MiB, ballooning off|
|Disk|15G, qcow2, on **`local`**|
|IP / Gateway / DNS|`192.168.8.104/24` / `192.168.8.1` / `192.168.8.1`|
|Start order|`1`|
### Memory

1. Click **104** → **Hardware**.
2. Double-click **Memory** → tick **Advanced** (bottom left).
3. **Memory (MiB):** `1024`
4. **Ballooning Device:** ☐ **untick**
5. **OK**

### CPU

1. Double-click **Processors**.
2. **Sockets** `1`, **Cores** `1`, **Type** `host` (already set).
3. **OK**

### Disk to 15G

1. Click **Hard Disk (scsi0)**. It shows about `size=3584M`.
2. **Disk Action → Resize**.
3. **Size Increment (GiB):** `11.5` → **Resize disk**.
4. Double-click **Hard Disk (scsi0)** and check that ☑ **Discard** and ☑ **SSD emulation** are ticked → **Cancel**.

### Cloud-Init

Click **104** → **Cloud-Init**. Double-click each line:

|Item|Value|
|---|---|
|User|`ubuntu` (already set)|
|Password|(leave empty)|
|DNS domain|(leave empty)|
|DNS servers|`192.168.8.1`|
|SSH public key|Keep the existing line, and add your Mac’s key on a **new line**|
|IP Config (net0)|**IPv4: Static**. IPv4/CIDR: `192.168.8.104/24`. Gateway (IPv4): `192.168.8.1`|

Your Mac’s key comes from running this in Terminal on the Mac:

bash

```bash
cat ~/.ssh/id_ed25519.pub
```

Then click **Regenerate Image** at the top.

### Step 6: Options

Click **104** → **Options**. Double-click each line:

|Option|Value|
|---|---|
|Start at boot|☑ Yes|
|Start/Shutdown order|Order: `1`|
|QEMU Guest Agent|☑ Use QEMU Guest Agent|
|Protection|☑ Yes|

### Step 7: Start

1. Click **Start** (top right).
2. Click **Console** and press **Enter** if it’s blank.
3. Wait **1–2 minutes** until you see:

```
vm-runner login:
```

Note: If you encountered this error, virtualization needs to be enabled in BIOS.
TASK ERROR: KVM virtualisation configured, but not available. Either disable in VM configuration or enable in BIOS.

### Step 8: Verify

**In the UI:** **104 → Summary**:

- IPs: `192.168.8.104`
- Memory: 1.00 GiB
- Bootdisk size: 15.00 GiB

**In pve → Shell:**

bash

```bash
qm config 104 | grep -E 'scsi0|memory|balloon|cores|onboot|startup|protection'
df -h /
ssh ubuntu@192.168.8.104 'hostname; ip -br addr; df -h /; free -h; systemctl is-active qemu-guest-agent; ping -c1 github.com'
```

Expected:

- `scsi0: local:104/vm-104-disk-0.qcow2,…,size=15G`, `memory: 1024`, `balloon: 0`, `cores: 1`
- `df -h /` on the host: **at least 10G** available
- Inside the VM: `vm-runner`, `192.168.8.104/24`, ~15G disk, ~0.9G RAM, `active`, and a reply from github.com

**From your Mac:**

bash

```bash
ssh ubuntu@192.168.8.104
```

### Step 9: Snapshot

**104 → Snapshots → Take Snapshot** → Name `base-os` → **Take Snapshot**.

### Troubleshooting

|Problem|Fix|
|---|---|
|`local` isn’t offered as Target Storage|Add **Disk image** to `local`’s Content (Datacenter → Storage → local → Edit)|
|Summary says “Guest Agent not running”|Wait 2 more minutes; the first boot is still installing it|
|VM got a different IP|Cloud-Init → IP Config isn’t Static. Fix it → **Regenerate Image** → **Reboot**|
|Can’t SSH from the Mac|Your Mac key wasn’t added. Add it in Cloud-Init → **Regenerate Image** → **Reboot**|
|Console blank|Press **Enter**; the template uses a serial console|
