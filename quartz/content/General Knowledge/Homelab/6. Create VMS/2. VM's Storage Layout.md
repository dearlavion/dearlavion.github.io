**`local-lvm`:** nothing changed here. 68.5G is under the 72.7G pool, so the VMs filling their disks can never fill the pool. Only snapshots can, so keep at most one per VM and check that `lvs pve/data` shows Data% below 80%.

**`local`:** vm-runner’s qcow2 file starts at about 3–4G and grows toward 15G as it pulls images. Check with `df -h /` and keep **at least 10G free**.

**RAM:** the headroom is now about 1.5 GB. Don’t give any VM more RAM without taking it from another one. If `free -h` on the host shows swap use climbing, lower devops from 1.5 to 1 GB first.

**Backups:** about 9–10G on `local` now. That’s enough for **vm-devops + vm-runner** (~2G each, 1–2 copies) plus etcd snapshots (MBs). A full set of all VMs (~10–14G) **no longer fits**; send those to a USB drive or NAS. The Kubernetes nodes can be rebuilt with Terraform anyway.
