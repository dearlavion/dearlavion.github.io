### Step 1: Create a Tailscale account (on your Mac)

1. In Safari, go to **[https://tailscale.com](https://tailscale.com)** and click **Get started**.
2. Sign in with **Google, Apple, Microsoft or GitHub**. Remember which one you used, because you’ll use the same one on every device.
3. If it asks how you’ll use Tailscale, choose **personal** use.

---

### Step 2: Install Tailscale on your Proxmox server

SSH in from your Mac:

bash

```bash
ssh root@192.168.8.50
```

Install it:

bash

```bash
curl -fsSL https://tailscale.com/install.sh | sh
```

Wait until it finishes. Then start it and log in:

bash

```bash
tailscale up
```

It prints a link like this:

```
To authenticate, visit:
     https://login.tailscale.com/a/g814a5ae47bd993b2
```

1. **Copy the link** (select it and press ⌘C) and open it in **Safari**.
2. Sign in with **the same account** as Step 1.
3. Click **Connect**.
4. Back in Terminal you’ll see `Success.`

**Get your server’s Tailscale address:**

bash

```bash
tailscale ip -4
```

It shows something like `100.65.11.90` . **Write it down.**

**SSH by Tailscale IP** :
**ssh root@100.65.11.90**

---

### Step 3: Install Tailscale on your Mac

1. Download it from **[https://tailscale.com/download/mac](https://tailscale.com/download/mac)**, or search “Tailscale” in the **Mac App Store**.
2. Open it. A Tailscale icon appears in the **menu bar** at the top right.
3. Click the icon → **Log in**, using **the same account**.
4. Allow the **VPN configuration** when macOS asks.
5. Make sure the menu shows **Connected**.

---

### Step 4: Check that both devices are connected

On your Mac’s menu bar, click the Tailscale icon. You should see **pve** in the device list. Or in Terminal on your Mac:

bash

```bash
tailscale status
```

If the `tailscale` command isn’t found on your Mac, just use the menu bar icon instead.

You can also see all your devices at **[https://login.tailscale.com/admin/machines](https://login.tailscale.com/admin/machines)**.

---

### Step 5: Test it

Try both of these from your Mac:

**SSH by Tailscale IP** (use yours):

bash

```bash
ssh root@100.101.102.103
```

**SSH by name** (MagicDNS, usually on by default):

bash

```bash
ssh root@pve
```

**Dashboard:** in Safari, open `https://100.101.102.103:8006` (accept the warning as before).

**Real test:** turn on your **phone’s hotspot**, connect your Mac to it (off your home Wi-Fi), and try `ssh root@pve` again. If it works, you can reach your server from anywhere. 🎉

### Step 6: Stop the server’s login from expiring (important)

By default, Tailscale asks each device to log in again **every 180 days**. For a server you can’t easily reach, turn that off:

1. Go to **[https://login.tailscale.com/admin/machines](https://login.tailscale.com/admin/machines)**.
2. Click the **⋯** next to **pve**.
3. Choose **Disable key expiry**.

---

### Step 7 (optional): Reach your VMs remotely too

Do this later, after creating the k3s VMs, if you want to reach them (`192.168.8.61` etc.) from outside. On the server:

bash

```bash
echo 'net.ipv4.ip_forward = 1' | tee -a /etc/sysctl.d/99-tailscale.conf
sysctl -p /etc/sysctl.d/99-tailscale.conf
tailscale up --advertise-routes=192.168.8.0/24
```

Then in the admin console: **Machines → pve → ⋯ → Edit route settings** → tick **192.168.8.0/24** → **Save**.

### Daily use

|Where you are|How to connect|
|---|---|
|**At home**|`ssh root@192.168.8.50`, or `ssh root@pve`|
|**Café or mobile data**|Turn Tailscale **on** (menu bar), then `ssh root@pve`|
|**Dashboard from anywhere**|`https://pve:8006` or `https://100.x.y.z:8006`|

After a server reboot, Tailscale starts by itself, so there’s nothing to redo.

---

### If something goes wrong

| Problem                              | Fix                                                                                                   |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `curl: Could not resolve host`       | DNS again. Check `cat /etc/resolv.conf` shows `nameserver 1.1.1.1`.                                   |
| `ssh root@pve` → “could not resolve” | Use the `100.x.y.z` IP instead, or enable **MagicDNS** under admin console → **DNS**                  |
| The Mac doesn’t see `pve`            | Check that both are logged into the **same** account and that the Mac’s Tailscale shows **Connected** |
